A chess engine in 4096 bytes of Python. Alpha-beta search with quiescence, iterative deepening on a fixed node budget, MVV move ordering, material + pawn piece-square evaluation. Plays the house gauntlet through the make.fun env.

Run: `MAKEFUN_ENV_URL=<env-url> python3 main.py`
